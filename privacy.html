Privacy Policy

Effective November 3, 2026

Fair Play (“the app”) is a desktop application that runs on the user's own computer. It has no servers of its own. This policy explains what information the app handles when a user connects their Google account.

Information the app accesses

When the user clicks “Connect Google Calendar” and grants permission, the app requests the Google Calendar scope https://www.googleapis.com/auth/calendar. It uses that access only to:

  • create two calendars in the user's Google account;
  • share those calendars with the email address the user enters;
  • create, update, move and delete the recurring events that the app itself created on those two calendars.

The event text is taken from the household's own data: a reminder title, the card name, the household's written standard of care, and the first names the household chose for the two partners. The app does not read the user's other calendars or events, contacts, email, or any other Google data.

Where information is stored

  • Household data file. The cards, schedules and notes are stored in a single file on the user's computer, in a location the user picks (often a Google Drive folder). The app does not upload this file anywhere else.
  • Sign-in token. The Google refresh token is stored on the user's computer, encrypted with the operating system's secure storage. It never leaves the device except in requests to Google.

Sharing and disclosure

The app's developer does not receive, collect, store, sell or share any user data. There are no analytics, advertising or tracking tools, and no data is sent to any third party. The only network traffic about Google data is between the user's computer and Google's own servers.

Limited Use

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Google user data is used only to provide the calendar features described above, is not used for advertising, and is not read by any person other than the user.

Your choices

  • Disconnect: use “Disconnect” in the app's Settings to delete the stored sign-in token.
  • Revoke access: remove the app at myaccount.google.com/permissions at any time.
  • Delete the events: delete the two “Fair Play” calendars in Google Calendar settings. Deleting the household file removes the app's local data.

Children

The app is not directed to children and does not knowingly collect information from them.

Changes

If this policy changes, the new version will be posted on this page with an updated date.
